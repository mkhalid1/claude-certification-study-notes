# Claude Certified Developer, Foundations (CCDV-F)

53 items, 120 minutes, scaled pass mark of 720 on a 100 to 1,000 scale. For engineers who build with the Claude API, Claude Code and MCP.

## Domains and weights

| # | Domain | Weight | About this many of 53 items |
|---|---|---|---|
| 1 | Agents and Workflows | 14.7% | 8 |
| 2 | Applications and Integration | 33.1% | 17 to 18 |
| 3 | Claude Code | 3.1% | 2 |
| 4 | Eval, Testing, and Debugging | 2.6% | 1 |
| 5 | Model Selection and Optimization | 16.8% | 9 |
| 6 | Prompt and Context Engineering | 11.0% | 6 |
| 7 | Security and Safety | 8.1% | 4 |
| 8 | Tools and MCPs | 10.6% | 6 |

A third of the exam is Applications and Integration, so real API work is the best preparation. Model selection is the second biggest block: know when each model tier, token budget and caching choice makes sense.
