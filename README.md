# Claude Certification Study Notes

Plain study notes for Anthropic's four Claude certification exams: what each one covers, how the domains are weighted, and how to plan your study time. Everything here is taken from Anthropic's official exam guides and Partner Academy pages. Nothing here is real exam content.

## The four exams at a glance

| Exam | Code | Built for | Questions | Time | Pass mark |
|---|---|---|---|---|---|
| Claude Certified Associate, Foundations | CCAO-F | Consultants, sellers and delivery leads. No coding. | 60 | 120 min | 720 / 1,000 |
| Claude Certified Developer, Foundations | CCDV-F | Engineers building on the Claude API, Claude Code and MCP | 53 | 120 min | 720 / 1,000 |
| Claude Certified Architect, Foundations | CCAR-F | Architects designing Claude systems end to end | 60 | 120 min | 720 / 1,000 |
| Claude Certified Architect, Professional | CCAR-P | Senior architects running Claude at enterprise scale | 63 | 120 min | 720 / 1,000 |

All four are closed book, proctored by Pearson VUE (online or at a test center), and mix multiple-choice with multiple-response items. Multiple-response items tell you how many options to pick. A certification is valid for 12 months. For now, only people at Claude Partner Network companies can register.

## Which one to take first

- You advise customers or sell Claude and do not write code: **Associate** ([notes](associate.md)).
- You write code against the Claude API, Claude Code or MCP: **Developer Foundations** ([notes](developer.md)).
- You design the system and own the tradeoffs: **Architect Foundations** ([notes](architect-foundations.md)).
- You already lead enterprise Claude deployments: **Architect Professional** ([notes](architect-professional.md)). There is no formal prerequisite.

## How to use these notes

1. Read the domain table for your exam and note the two or three biggest domains. They decide most of your score.
2. Take a timed, domain-scored diagnostic before you study, so you know where your gaps are. A free 25-question one for each exam is linked in each file.
3. Study the weakest big domain first, then re-test.
