# Glossary

Terms you will meet in the exam guides, on the exams and in these notes. Product terms are described at the level the exams use them. For full detail, check Anthropic's documentation.

## Exam terms

| Term | Meaning |
|---|---|
| **Cut score** | The minimum scaled score to pass: 720 on every Claude certification exam. |
| **Domain** | One of the content areas in an exam blueprint, each with a published weight. |
| **Exam guide** | Anthropic's official document for each exam: format, domains, skill statements and sample questions. |
| **Form** | One version of an exam. Different candidates may get different forms. |
| **Multiple response** | An item that asks you to choose more than one option. It tells you how many. |
| **OnVUE** | Pearson VUE's online proctored delivery. |
| **Scaled score** | A score on a 100 to 1,000 range that equates results across forms of slightly different difficulty. |
| **Scenario** | A realistic production context that frames a set of questions. Architect, Foundations draws 4 scenarios from a bank of 6. |
| **Skill statement / task statement** | A line in the exam guide describing what items in a domain measure. |
| **Unscored item** | A trial item on the 70-item forms that does not count toward your score and is not identified. |
| **Weight** | The approximate share of scored items drawn from a domain. |

## Product and practice terms

| Term | Meaning |
|---|---|
| **Agent** | A system where Claude decides which steps to take and which tools to call to reach a goal, rather than following fixed steps. |
| **Agent SDK** | Anthropic's toolkit for building agents with the same building blocks as Claude Code. |
| **Artifact** | A standalone piece of content Claude creates in the chat interface, such as a document or a small app. |
| **CLAUDE.md** | A file that gives Claude Code persistent project or user instructions. |
| **Connector** | A link from Claude to an external tool or data source, often through MCP. |
| **Context window** | The amount of text Claude can consider at once in a conversation or request. |
| **Escalation** | Handing a case to a person when the decision, risk or accountability belongs to them. |
| **Eval** | A repeatable test of model or system output against defined criteria. |
| **Hallucination** | Confident output that is not supported by the source or by fact, such as an invented citation. |
| **Hook** | In Claude Code, a configured command that runs automatically at a defined point, such as before or after a tool call. |
| **MCP (Model Context Protocol)** | An open protocol that lets Claude connect to tools and data sources through servers. |
| **Plan mode** | A Claude Code mode for exploring and planning a change before making edits. |
| **Project** | In the Claude app, a workspace with shared instructions and knowledge files that apply to every chat in it. |
| **Prompt caching** | Reusing a stable prompt prefix across requests to cut cost and latency. |
| **Skill** | A packaged set of instructions and resources Claude can load for a specific kind of task. |
| **Structured output** | Output in a defined machine-readable format, such as JSON matching a schema. |
| **Subagent** | An agent started by another agent to handle part of a task in its own context. |
| **System prompt** | Instructions that set Claude's role, rules and context for a conversation or application. |
| **Tool use** | Claude calling a function or service you define, with arguments it chooses, and using the result. |
